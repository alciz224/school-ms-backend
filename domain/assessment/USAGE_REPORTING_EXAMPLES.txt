ReportCard Generation (Staff)
--------------------------------
POST /api/v1/assessment/report-cards/generate/
{
  "classroom_id": 12,
  "term_id": 5,
  "force": true
}

Response:
{
  "report_cards_created": 25,
  "report_cards_updated": 0,
  "subjects_created": 125
}
