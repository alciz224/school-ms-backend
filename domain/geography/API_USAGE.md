# Geography API Usage Guide (Frontend)

Base path: `/api/v1/geography/`

## Reference Endpoints (CRUD)

### Countries
- `GET /countries/`
- `POST /countries/`
- `GET /countries/{id}/`
- `PATCH /countries/{id}/`
- `DELETE /countries/{id}/`

### Regions
- `GET /regions/`
- `POST /regions/`
- `GET /regions/{id}/`
- `PATCH /regions/{id}/`
- `DELETE /regions/{id}/`

### Administrative Units
- `GET /administrative-units/`
- `POST /administrative-units/`
- `GET /administrative-units/{id}/`
- `PATCH /administrative-units/{id}/`
- `DELETE /administrative-units/{id}/`

### Localities
- `GET /localities/`
- `POST /localities/`
- `GET /localities/{id}/`
- `PATCH /localities/{id}/`
- `DELETE /localities/{id}/`

---

Permissions follow the project’s default API policy (authenticated users with proper role).
